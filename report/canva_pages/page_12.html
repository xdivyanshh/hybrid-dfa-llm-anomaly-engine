THE 7-TUPLE TURING SANITIZER

Before any anomalous log record crosses the trust boundary into cloud LLM APIs, it undergoes deterministic in-place tape manipulation by a formal 7-tuple Turing Machine: M_TM = (Q, Γ, b, Σ, δ, q0, F). The tape head scans for sensitive auth tokens and passwords, permanently overwriting them with redaction symbols.

FORMAL SPECIFICATION: 7-TUPLE TAPE AUTOMATON
M_TM = (Q, Γ, b, Σ, δ, q0, F)
• Q = {q_seek, q_token, q_mask, q_accept}  (4 Tape Control States)
• Γ = ASCII ∪ {'X', '␣'}  (Tape Alphabet containing redaction character 'X')
• b = '␣'  (Blank Symbol representing boundary delimiters)
• δ: Q × Γ → Q × Γ × {L, R, S}  (Single-head linear in-place rewrite transition)

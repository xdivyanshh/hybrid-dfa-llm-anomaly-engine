Real-Time Interactive Presentation Dashboard and Engine Toolchain

The project includes a production C++14 engine along with an interactive visual web dashboard designed for academic evaluation, live viva demonstrations, and operational monitoring.

C++14 Engine Toolchain

• Language Standard: C++14 (ISO/IEC 14882)
• Compilation Command:
g++ -std=c++14 -O2 -I include src/*.cpp -o anomaly_engine.exe
• Memory Architecture: Zero dynamic heap allocations in hot-path state transitions; transitions use lookup arrays.
• Unit Testing: Full assert test suite (test_runner.exe) validating Table 4 test cases.

Web Visualizer Architecture

• Location: web/index.html (Served via Python on Port 8000).
• Reactive Nodes: Nodes q₀ … q₄, qE animate with teal/red glowing halos as tokens are consumed.
• Moore Dials: Visual counter tracking consecutive IP failures.
• Dynamic Tape: Displays memory cells being overwritten by the Turing head.

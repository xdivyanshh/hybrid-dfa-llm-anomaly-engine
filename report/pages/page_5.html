The Algorithmic Dilemma

Evaluating the Extremes: Pure Symbolic Rules vs. Pure Neural Models

Neither pure classical regex rule engines nor pure modern Large Language Models solve the log triage problem in isolation. A viable production architecture must bridge the two.

Pure Rule Engines

• Pro: Sub-millisecond execution.
• Con: Incapable of explaining unknown anomalies.
• Con: High maintenance overhead; regex rules accumulate into unmaintainable technical debt.
• Vulnerability: Catastrophic ReDoS locks CPU cores.

Pure LLM Triage

• Pro: Rich semantic explanations and forensic remediation hints.
• Con: 1–2 orders of magnitude too slow.
• Con: Prohibitive operational costs ($15k+/month for basic workloads).
• Failure: API rate limits cause denial-of-service during attacks.

Neuro-Symbolic Hybrid

• Symbiosis: Fast deterministic automaton as the gatekeeper.
• Efficiency: 95% of routine logs bypass cloud APIs.
• Explainability: Only genuine anomalies reach the neural LLM.
• Security: PII scrubbed on local Turing tape before egress.

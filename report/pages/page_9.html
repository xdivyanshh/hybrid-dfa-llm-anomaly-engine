The Minimal Baseline DFA

Mathematical 5-Tuple Formulation and State Dynamics

The baseline structure recognizer is formally defined as a Deterministic Finite Automaton (DFA) 5-tuple:
M = (Q, Σ, δ, q₀, F)

Formal 5-Tuple Specification

• State Set Q: { q₀, q₁, q₂, q₃, q₄, qE }
• Alphabet Σ: { LEVEL, IP, USER, STATUS, OTHER }
• Start State q₀: The initial state prior to consuming tokens.
• Final / Accept State F: { q₄ } (Double Circle).
• Trap / Dead State qE: An absorbing state representing rejection.

Semantic State Interpretation

• q₁: Successfully parsed and validated LEVEL token.
• q₂: Successfully parsed and validated IP token.
• q₃: Successfully parsed and validated USER token.
• q₄: Successfully parsed STATUS (Grammar satisfied).
• qE: Irreversible trap state entered on unexpected token.

Threat Model & Hardening

Adversarial Robustness and Defense-in-Depth Protections

Like any cyber defense mechanism, the hybrid anomaly engine itself is a target for intelligent adversaries attempting evasion, timing side-channel exploitation, or denial of service.

Adversarial Attack Vectors

• Token Smuggling: Inserting whitespace or null bytes to split tokens across lexeme boundaries.
• DDoS on Slow Path: Flood of malformed lines intended to exhaust LLM API budgets and saturate queues.
• Slow Brute-Force: Spreading password guesses across multiple IP subnets to evade the 3-failure Moore threshold.

Engine Countermeasures

• Strict Canonicalization: The lexer strips control characters prior to regex compilation.
• Bounded Queue Drop: Excess anomalies beyond queue capacity trigger local logging without blocking engine threads.
• Global Sliding Window: Augments per-IP tracking with global subnet rate limiting.
